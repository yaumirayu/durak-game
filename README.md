# Дурак — 2–6 игроков

Три режима: боты, локально на одном устройстве и онлайн. Подкидной и переводной; колоды 36 и 54 карты (в 54 два джокера по указанному домашнему правилу).

## Онлайн

Firebase Anonymous Authentication подтверждает личность игрока. Cloudflare Workers Free и SQLite-backed Durable Objects хранят колоду, раздают карты и проверяют ходы. Организатор получает только собственную руку. В браузере нет ключа администратора, полной колоды или чужих рук.

Realtime Database для игрового состояния не используется. `database.rules.json` запрещает клиентский доступ ко всей базе. Firebase остаётся на Spark, Cloudflare — на Workers Free. При исчерпании бесплатных квот доступ может временно прекратиться. Платные планы и биллинг не требуются.

Комната действует 24 часа. Перезагрузка вкладки восстанавливает место через анонимную сессию Firebase в этой вкладке. Очистка данных браузера или закрытие сессии может лишить игрока прежней личности. Организатор не обязан держать компьютер включённым: сервер работает в облаке. Отключившееся место ждёт возвращения игрока; автоматическая замена ботом пока не реализована. Если игрок не вернётся, его ход задержит партию.

## Развёртывание

1. Включить Anonymous в Firebase Authentication.
2. На бесплатном Cloudflare выполнить `wrangler deploy` с `wrangler.jsonc`.
3. В `index.html` задан `SERVER_URL`: `https://durak-game-server.yaumirayu.workers.dev`. При смене сервера обновить адрес.
4. Опубликовать `index.html` на GitHub Pages.
5. Опубликовать `database.rules.json` в Firebase Console. Не помещать серверное состояние в доступную клиентам ветку базы.

Онлайн синхронизируется каждые три секунды, в скрытой вкладке — каждые десять. Сервер принимает только собственные ходы игрока, проверяет идентификатор партии и версию положения. Колода перемешивается криптографическим генератором. Состояние сохраняется в Durable Object после каждого принятого хода.

Владелец облачного аккаунта имеет административный доступ к серверу. Приватность защищает игроков, включая организатора комнаты, от чтения чужих рук через игровой клиент; не защищает от администратора инфраструктуры, сговора участников или передачи ими своих карт друг другу.

## Проверки

`node tests/server.test.mjs` — 100 полных партий, уникальность карт, ограничения мест, приватные представления, неверная очередь, чужие карты, устаревшие ходы, повторная отправка и неизменность привязки руки к игроку после выхода организатора. Сторонние пакеты для этих проверок не нужны.
